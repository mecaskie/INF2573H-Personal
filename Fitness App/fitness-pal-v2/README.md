# Fitness Pal — Version 2

[Open the live prototype](https://fitness-pal-prototype.able-ape-0307.chatgpt.site/v2/)

Fitness Pal is a mobile-first fitness planning prototype featuring Pal the Gorilla, conversational onboarding, weekly and daily routine views, workout demonstrations, daily check-ins, progress tracking, meal ideas, and avatar rewards.

## Files

- `index.html`: browser-ready exported prototype. Download it and open it in a browser. The sandboxed iframe and Content Security Policy are preserved.
- `source/fitness-pal-version-2.html`: editable application source containing the HTML, CSS, JavaScript, and embedded images. It is the source fragment used to generate the exported page.

The prototype uses sample data and guided local conversation responses. Account creation, external integrations, and community connections are demonstrations. Google Sans and the exported runtime's external resources require an internet connection.
