# Gym Buddy — Sketch 0

Open `index.html` in a modern browser to run the mobile demo. Keep `styles.css` and `app.js` in the same folder. No build or installation is required.

This copy includes onboarding, goal and health-note selection, daily readiness and sleep check-ins, workout plans and completion tracking, calorie estimates, meal logging, and scripted coach responses. It starts from onboarding while retaining saved browser data.

Source: the local Gym Buddy Sketch 0 demo, originally published on the team repository's `maecel/sketch-0` branch; this copy includes the subsequent onboarding startup change.

This is a prototype using local rules and browser storage, not a clinically validated prediction system. Carbohydrate and fat progress bars are illustrative. Google Fonts requires internet access; fallback fonts are provided.

Verification: `node --check app.js` passed before publication. Browser interaction testing was not performed for this copy.
